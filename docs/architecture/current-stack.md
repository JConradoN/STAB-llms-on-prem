# Current Stack

## Infra base

- Ubuntu 24.
- Servidor local único para dev e experimentação.
- GPU RTX 3060 12 GB.
- Ollama como runner principal local.

## Ferramentas relevantes

- LiteLLM para gateway/roteamento.
- Claude Code e Gemini CLI como possíveis agentes CLI.
- OpenClaw como ambiente/agente em estudo.
- n8n para automações e possíveis fluxos.
- Open WebUI para interface/local ops.
- OpenCode e Qwen CLI como apoio de experimentação.
